# UAV Health Monitoring

## Team Members
Prissha Chawla [CS], Siddharth Urankar [CS], Ally Blair [ME]

# User Stories

1. As a UAV operator, I want to automatically detect motor or propeller faults during 
flight, so that I can ensure safe landing and prevent crashes in mission-critical 
operations.
2. As a drone fleet manager, I want to track battery health and predict remaining flight 
time, so that I can plan missions more reliably and reduce unexpected downtime.
3. As a remote operator using a drone-in-a-box system, I want in-flight monitoring of 
propeller damage, so that I can identify issues that are not visually observable and 
avoid risky deployments.
4. As a UAV maintenance technician, I want pre-flight diagnostics to flag potential 
motor or propeller issues, so that I can repair or replace components before they fail 
in operation.
5. As an aviation safety regulator, I want a standardized health monitoring framework 
integrated into UAVs, so that I can improve operational safety and ensure 
compliance with safety management systems.
